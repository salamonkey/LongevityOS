Vitalis Design System

The canonical specification for the Vitalis health-companion app: tokens, components, patterns and rules. This file is self-contained — the :root block at the top of its stylesheet is the source of truth for every token. Product code must reference token names, never raw literals.

Start

About & principles

Vitalis organises personal health prevention — vaccinations, screenings, recurring appointments and documents — for health-conscious adults from about 45, plus the family members they administer. It never diagnoses and never replaces a doctor; it reminds, organises and reassures.

Calm over urgent

Health data is sensitive. Muted cool palette, generous whitespace, soft elevation. Red is reserved for genuinely due items — never decoration.

One clear next action

Every screen answers "what do I do now?". Status is always visible as colour + label, never colour alone.

Confident, not clinical

Rounded geometry, one warm teal accent and restrained motion make prevention feel encouraging rather than medical.

Legible at arm's length

Body text never below 15px, captions never below 11px, tap targets never below 44px.

Voice & content

German is the primary language and uses the informal “du”. Tone is calm, minimal and casual — short sentences, no alarm, no jargon, no emoji. English is a full peer locale.

Typography

Public Sans is the single typeface (400/500/600/700/800). One family, weight and size carry all hierarchy — no second display face.

body-strong · 15/22 · 600Grippeimpfung
callout · 13/18 · 500Auffrischung fällig
caption · 12/16 · 500Dienstag, 24. Juni
overline · 11/14 · 600 · .04emHeute fällig
micro · 8.5–10.5 · 600–700Jun · Q3 26 · Impfen— chart axes, tab labels, legends only
Rules. Overline is always uppercase with .04em tracking and --text-muted, used for section labels. Display/title get -.01em tracking. Never use more than three sizes in one card.

Minimum sizes. Content text never goes below 11px — anything the user reads to understand or act (titles, body, subtitles, badges, buttons, form labels, captions). A separate micro tier of 8.5–10.5px is permitted only for chart axis labels, tab-bar labels, chart legends and dense chart row captions, where the adjacent icon, bar or list row already carries the meaning. Micro type is always 600–700 weight for legibility, and never the sole carrier of an action or a status.

Motion

Motion is purposeful and short: it explains where things came from and draws attention to what needs action. Nothing loops except the two "needs attention" pulses.

KeyframeDuration / easingApplied to
v-up280ms ease, stagger 60msScreen content and timeline nodes entering
v-dot500ms --ease-spring, stagger 80ms (120ms delay)BodyMap status dots popping in
v-ping1.9s ease-out, infiniteRing around "act now" BodyMap dots
v-halo2s ease-out, infiniteHalo behind the "Heute" timeline marker
v-slidein260ms easeFull-screen detail pages (region, event, task, settings)
v-slide260ms easeBottom sheets rising
v-draw500ms ease, origin topTimeline spine drawing itself
v-fade180msScrims and overlays

Numeric reveals (the score) count up once on mount over ~900ms. Respect prefers-reduced-motion: disable the two infinite pulses and the count-up, keep the slide-ins under 120ms.

Dot construction

Three stacked layers in a 26px grid cell: an optional pulsing ring (v-ping, action only), a 16–20px halo of the hue at 22% opacity, and an 11–13px solid core with a 2px white border and a tight shadow. The selected dot is the larger variant — size means selection, not severity. Dots enter with v-dot, 80ms stagger.

Assets. Silhouettes live at assets/body-male.png and assets/body-female.png (palette-tinted, alpha), and are additionally embedded as data URIs in assets/body-silhouettes.js (window.VITALIS_BODY) so the map renders without an external image fetch. Six canonical regions: kopf, impf, herz, haut, bauch, beine.

Why a Gantt. It answers “how long am I covered?” and “when does this cycle come round again?” at a glance — e.g. Tetanus as one long green span to 2031 versus a flu booster whose window has just run out. Keep it calm: no more than four lanes, no bar labels inside bars, and the only motion is the spine draw plus the action pulses.
Patterns

Full-screen detail pages

Region, event and task details all share one anatomy, slide in with v-slidein over the tab bar, and are dismissed with the TopBar chevron.

  1. TopBar — back chevron, title, mark.
  2. Hero card — 54px tone-soft icon tile, title, one-line status sentence.
  3. Sections — "Offen", "Anstehend", "Verlauf" as overline-labelled ListRow groups (empty sections are omitted entirely, never shown as empty shells).
  4. Primary action — full-width lg button: "Als erledigt markieren", "Verschieben", "Impfung eintragen", "Termin planen".
Status changes are always explicit and reversible. Marking done navigates back with the item moved to "Verlauf"; snoozing offers a date. Nothing silently disappears from a list on tap.

Localisation

German and English are peers, switchable in-app (Settings → Sprache) with immediate effect on every string — tabs, labels, sample data, dates and formats. No reload, no restart.

RuleDetail
No hard-coded copyEvery user-visible string resolves through the dictionary (t('key')). Data records carry { de, en } pairs resolved by a helper.
Formats follow localeDE: TT.MM.JJJJ, "Dienstag, 24. Juni", "09:30 Uhr". EN: DD/MM/YYYY, "Tuesday, June 24", "09:30".
Layout toleranceGerman runs ~25% longer. Never fix a label's width; tab labels must survive "Vorsorge" at 10.5px without truncation.
Keys are semanticbadge_due, sec_history — never English-word keys that drift from meaning.

Rules

Do & don't

Do

  • Reference semantic tokens (--color-primary, --space-4) in all product code.
  • Give every screen one primary action and one accent moment.
  • Navigate to a detail page for any status change.
  • Keep list rows as separate cards with a 10px gap, laid out with flex/grid gap.
  • Pair every status colour with a word.
  • Pin circular elements with explicit size + flex:none.
  • Route all copy through the dictionary, both locales.

Don't

  • Hard-code hex values, px radii or shadows that duplicate a token.
  • Introduce a new font, a second display face, or emoji.
  • Use red for anything other than "act now".
  • Stack multiple gradients or glows on one screen.
  • Mutate data on row tap, or let items vanish without confirmation.
  • Add a third sex option to the clinical sex control.
  • Ship any string that exists in only one language.
  • Diagnose, interpret results, or omit the medical disclaimer.
